# Victor Kyalo — Personal Portfolio Website

A responsive personal portfolio website designed and built using semantic **HTML5** and **CSS3** (Flexbox & CSS Grid) to showcase my background, technical skills, projects, and contact details.

## Live Website
🔗 **Live Demo:** [https://github.io](https://github.io)

## Features
- **Bento-Grid Dashboard Layout:** Clean card-based design built with CSS Grid and Flexbox.
- **Semantic HTML5:** Uses `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>`.
- **Responsive Design:** Adapts smoothly across desktop, tablet, and mobile screens.
- **Interactive Elements:** Smooth anchor navigation, hover transitions, and a styled contact form.

## Project Structure
- `index.html` — Main semantic HTML structure.
- `style.css` — External stylesheet containing theme colors, layouts, and media queries.
- `images/` — Folder storing profile picture, project thumbnails, and preview screenshots.
